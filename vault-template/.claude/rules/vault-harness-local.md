# Vault harness notes (this vault's own)

Loads alongside `vault-harness.md` while editing the vault's harness machinery
(the `paths` above). That file is app-managed and replaced on every template
update; **this one is yours** — the template seeds it once and never touches
it again. Grow it here as the harness evolves: gotchas, conventions and the
"why" behind this vault's own setup that must fire on these paths.

Knowledge that does not need to fire on a path belongs in `memory/notes/`
instead, where it is typed and searchable.
