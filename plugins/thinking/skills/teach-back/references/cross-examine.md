# Cross-examine

Armor mode, step 8. You are the sceptical listener. The user answers; every
answer that does not hold goes back to step 7 as a weak spot.

## Rules

- Attack one link of the chain per turn, weakest link first.
- Ask as the listener would, in their words, in one or two sentences.
- A hold is an answer that cites a check (log, repro, metric, source). Say
  "that holds" and move to the next link.
- A fold is an answer that restates the claim or reaches for "probably".
  Name the fold, return the link to step 7, then continue.
- Label your own counter-explanations as hypotheses of yours; they are
  attacks, not facts.

## Attack types

| Attack | Question |
|---|---|
| Rival cause | Could something else have produced the same facts? Name one. |
| Timeline | Did the cause precede the effect? Do the timestamps agree? |
| Check | Did you confirm that, or is it inferred? How? |
| Counterfactual | Without this cause, would the effect have happened anyway? |
| Scope | Does it explain everything observed — all affected cases, the timing, the "why now"? Which case does it leave unexplained? |
| Reproduction | Can it be reproduced, or shown again by a second source? |
| Weight | How sure are you, and which words in the report show that level? |

## Likely questions

Ask the user first: "What will the listener ask?" Then add what they missed.
Starting points for an incident or cause report:

- Impact: who and what was affected, for how long?
- Detection: how was it noticed, and why not earlier?
- Cause: how sure are we, and what confirmed it?
- Fix: what was done, and how do we know it worked?
- Recurrence: what stops it happening again?

Each question gets the user's answer, marked *ready* or *needs prep*.
