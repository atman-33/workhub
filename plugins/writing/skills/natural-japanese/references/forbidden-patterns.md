# 禁止語・LLM常套句カタログ

ここに並ぶ表現の多くは、単体で見れば誤りでも失礼でもない。問題は頻度と文脈で、LLMが好んで使う型にはまった言い回しを積み重ねると、文章全体が「誰かが書いた」のではなく「生成された」ように読めてしまう。だから各カテゴリには、その表現がなぜAI臭さの引き金になるのかを添える。丸暗記して禁止語リストと照合するのではなく、理由を理解したうえで自分の文章を読み直す材料にしてほしい。

`scripts/lint.mjs` は、このうち機械的に拾える一部（前置き・定型の結び・比喩動詞・頻出語・絵文字・ダッシュなど）だけを指摘する。こちらは検出精度より網羅性と説明を優先していて、lint に引っかからない類似表現も含む。

**書き直しでは機械的に置換しない。** ここに並ぶ表現を見つけても、元の文の主張・比重・言い切りの強さ・文の働きを動かさない範囲でだけ直す。手順は `meaning-preservation.md` を先に読む。

**日常語は禁止語にしない。** 「最後に」「まさに」は人間の文章にも普通に出る日常語で、AI特有の手癖ではない。この2語は禁止語に含めない。「重要なのは」「このように」「不可欠」「ポイントは」「さて、」も人間側で一定数出るので、見つけても弱いシグナルとして扱い、機械的に削らない。

## 結論の押し付け・まとめ口調

「と言えるでしょう」「と言えるだろう」「と言えます」「ということになるでしょう」「のではないでしょうか」「結論から言うと」「結論として」「まとめると」「総じて」「いかがでしたか」「いかがでしょうか」

これらは、読み手に判断の余地を残さず結論を先回りして提示する型で、AI要約タスクの訓練データに大量に出現する。人間が書くエッセイや記事では、結論はもっと言い切るか、逆にもっと迷いを残したまま終わることが多い。「〜のではないでしょうか」は特に、断定を避けたいときの安全な逃げ道として過剰に使われがちで、多用すると意見のない文章に見える。

## 過剰な強調・持ち上げ

「非常に重要」「極めて重要」「重要なのは」「大切なのは」「ポイントは」「言うまでもなく」「言うまでもありません」「まさしく」

（「まさに」は日常語で、AI特有の手癖ではないため対象から外してある）

強調語は本来、他と比べて際立つ箇所にだけ使うから強調になる。LLMは文章全体の温度を均そうとする性質があり、結果としてほぼ全段落に強調語が置かれる。強調が均等に配置された文章は、読み手からすると「どこが本当に大事なのか」が逆に分からなくなる。強調したいなら、語で言うのではなく、その一文だけ短く言い切るなど構造で示すほうが伝わる。

## 定型導入・空疎な接続

「さて、」「それでは、」「このように」「このような中」「ここで注目したいのは」「見ていきましょう」「紹介していきます」「解説していきます」「深掘りしていきます」

これらは内容を運ばない「橋渡し語」で、次の話題に移る合図として便利なぶん、書き手の思考の跡が残らない。人間が書く文章の転換は、たいてい具体的な出来事や疑問がきっかけになっていて、「さて」のような無色の合図では起きない。段落の冒頭がこの手の定型句だらけになっていたら、内容そのもので前の段落とつなげられないか考える。

## 予防線・免責的な言い回し

「一概には言えません」「個人差がありますが」「あくまで一例ですが」「〜という側面もあります」「〜とも限りません」

責任の所在をぼかす言い方は、事実に対して慎重であろうとする姿勢自体は悪くないが、頻出すると「何も言っていない」文章になる。LLMは反証可能性を減らすよう訓練されているため、断定を避ける保険の表現を無意識に積み上げる。言い切れないなら、条件を具体的に書くほうが誠実で、かつ自然に読める。

## 感嘆・共感の演出

「〜なんですよね」「〜んです」の多用、「驚くべきことに」「興味深いことに」「実は」の乱用、体験の後にすぐ続く「いかがでしょう、あなたも〜」

これらは読者との距離を縮める演出だが、演出だけが浮いて中身が伴わないと空々しく響く。人間の文章では、驚きや発見は語り口の演出でなく、直前に書かれた具体的な事実の落差そのものから伝わる。「実は」と書く前に、その情報が本当に意外かどうかを確認する。

## 三点構成・網羅の圧力

「〜には、大きく分けて3つの理由があります」に類する、無理に3つに整理してから列挙する型

物事を3つにまとめるのは分かりやすさの型として便利だが、現実の理由や要素はきれいに3分割できるとは限らない。LLMは構造化を好むため、実際には2つしかない論点や、4つ目・5つ目がある論点まで3つに丸めがちになる。数を先に決めず、論点の数だけ書く。

## 対比の多用（否定→肯定）

「〜ではなく、〜」「〜だけでなく〜も」を1本の文章で3回以上繰り返す構文

対比で言いたいことを強調する技法自体は自然な日本語にもあるが、同じ型を繰り返すと読み手はリズムのパターンに気づき始め、内容より構文が目立つようになる。`scripts/lint.mjs` の `negative_parallelism` は「ではなく」を1文ずつ指すだけなので、文書全体で何回出たかは自分で数える。3回を超えたら、少なくとも1箇所は対比構文をやめて素直な肯定文か具体例に置き換える。

## 体言止め・断定的箇条書きの過用

見出しでもないのに文末を名詞で切る、内容の薄い箇条書きを並べて説明した気になる

体言止めはリズムを引き締める効果があるが、地の文で20%を超えて使われると、読み手は文の続きを予期できず疲れる。箇条書きも同様で、本来つながりのある思考を機械的に分断してしまうと、書き手が考えを追っていない印象を与える。比率は `manual-checklist.md` の5で目視する。

## 段落構造の均質化

すべての段落を同じ接続詞で始める、すべての段落を同じ文数（例: 3文）でそろえる

段落頭の接続詞率と段落あたり文数の変動係数は、どちらも `manual-checklist.md` の6と7で目視する。人間の文章では、深く語る段落と一言で済ませる段落が混在するのが普通で、揃いすぎた段落構成はテンプレートで生成された印象を与える。詳しい直し方は `references/revision-guide.md` の濃淡設計を参照。

## 語彙の使い回し

同じ内容語（名詞・動詞・形容詞・副詞）を言い換えずに繰り返し使う

言い換えの多様性が低いと、TTR（Type-Token Ratio）やMTLDのような語彙多様性指標が下がる。人間の書き手は無意識に類義語や具体的な別表現に言い換えるが、LLMは統計的に最も自然な（＝最頻出の）語を選び続けるため、同じ語がループしやすい。`manual-checklist.md` の9で目視する。

## 正面から系（出典: [k16shikano の日本語技術文書規範](https://gist.github.com/k16shikano/fd287c3133457c4fd8f5601d34aa817d) に基づく japanese-tech-writing の規範から）

「正面から扱う」「正面から見る」「正面から書く」「正面から立てる」「正面から回収する」

中身の代わりに姿勢だけを宣言する言い方。「この理論を正面から扱う」と書いても、実際に何をどう論じるかは一切増えていない。LLMは論証の実質を書く代わりに、こうした姿勢表明で「ちゃんと書いている感」を出しがちになる。姿勢を宣言する代わりに、実際に扱う内容そのものを書く。

## 空虚な形容（出典: japanese-tech-writing の規範から）

「不可欠」「核心的」「鍵となる」「根本的な」「多角的」「包括的」「総合的」

主張の中身を説明せず、強調や網羅性の感触だけを足す形容語。「〜は不可欠である」だけでは何がどう不可欠なのかが分からず、「多角的に分析すると」も実際にどの角度から見たかを書かない限り空語になる。強調したいなら、その形容語の代わりに具体的な根拠や視点そのものを書く。

## 空虚な動詞・予告口調（出典: japanese-tech-writing の規範から）

「掘り下げる」「深掘りする」「言語化する」、「〜について見ていく」「〜を探求する」

何をどう書いたか・どう言語化したかを示さないまま、作業したことだけを宣言する動詞。「本章ではこの問題を深掘りする」と書いても、深掘りの中身は次の文以降で初めて分かる。宣言を消して、深掘りした内容そのものから書き始める。

## プレゼン的数宣言（箇条書き化への助走）

「理由は3つあります」「軸は2つあります」「ポイントは主に以下の通りです」

これから話す項目の数を冒頭で宣言してから綺麗に並べる型。プレゼンや要約タスクの学習データに大量に含まれるためLLMが極めて好むが、文章として読むと教科書的・テンプレ的で体温が消える。数を先に宣言せず、理由や背景の内容そのものから地続きで語る。

## 演出的な決め文・自己陶酔調

「〜ところまでが仕事です」「〜に他なりません」「これこそが〜の真髄です」「〜と言っても過言ではありません」

キリッとした決め台詞で文末を演出し、自己満足的に話を締めくくる型。文章全体の論証や事実の重みではなく、語り口のカッコよさで読者を圧倒しようとするため、読者には空々しく響きやすい。事実を淡々と述べる（「〜までを扱います」「〜が特徴です」）。

## ダラダラ引き伸ばし・水増し講釈（読者時間の浪費）

「近年、〜の重要性がますます高まっています」「ここでは〜について詳しく見ていきましょう」「つまり、〜ということでもあります」

誰もが知っている当たり前の一般論から入ったり、予告を二重に置いたり、同じ内容を言い換えて文字数を水増しする型。AIが「丁寧に解説しよう」とするあまり情報密度が薄まり、読者に「早く本題に入れ」「長くて読む気が失せる」という強いストレスを与える。不要な前置きや蛇足の講釈は徹底的に削ぎ落とし、最短で本題の核心に入る。

## 比喩動詞・AI偏愛動詞

抽象的な事象や技術操作を、安易な比喩動詞で言い換える型。直すときは、比喩の語は平易な言葉に開き、その語が運んでいた**含み**（不注意、待ちくたびれ、後悔、目立たないが確かにある、など）は別の言葉で残す。

| 表現 | 直す方向 |
|---|---|
| 効く・効いてくる（「地味に効く」） | 「目立たないながらも役に立つ」「じわじわ助けになる」。「地味に」の含みは残し、「確かに」などの強調語は足さない |
| 壊れる（データ・システム・設計に対して） | 「おかしくなる」「使えなくなる」。意味の広さが同じ言葉にする。「整合性が失われる」「不整合が生じる」と専門用語にするのは、元の文や前後から整合性の話だと分かるときだけ。時計や機械、身体の文字どおりの「壊れる」は残す |
| 倒す（「安全側に倒す」） | 「安全を優先する」「〜の扱いに統一する」「除外する」 |
| 溶かす（「時間を溶かした」） | 「時間がかかってしまった」「時間を費やしてしまった」。後悔の含みは残す |
| 潰す（「1つずつ潰す」） | 「1つずつ直す」「消す」「解決する」 |
| 踏み込む・引き返す・添える・収斂する | 「詳しく調べる」「元の状態に戻す」「渡す・つける」「落ち着いた・決まった」 |
| 静かに・黙って・沈黙する | 「気づかないうちに」「知らないうちに」のように、気づけない幅のまま書く。「エラーを出さずに」「通知なく」と仕組みの話にするのは、元の文や前後からそう分かるときだけ |

「骨が折れる」「手を焼く」「目から鱗が落ちる」「首を長くして待つ」のように、日本語で定着した慣用句は、AIっぽい比喩として扱わずそのまま残す。業務文書でも、意味を取り違えるおそれがなければ残す。迷ったら、AIが広まる前の人の文章でもふつうに見かける言い方かどうかで決める。見かけるなら残す。

## 直訳由来の表現

英語の表現をそのまま日本語にした結果として出る型。

| 英語の原表現 | 直訳調 | 自然な言い方 |
|---|---|---|
| the moment ... | 「〜した瞬間（に）」 | 「〜するとすぐに」「〜した時点で」 |
| single source of truth | 「正本にする」 | 「信頼できる唯一の情報源とする」「マスターデータとする」 |
| point to / suggest | 「〜を指している」「〜を示唆している」 | 「〜を表している」「〜と考えられる」「〜を意味する」 |
| load-bearing | 「構造を支える」 | 「不可欠な」「根幹となる」「外せない」 |
| delve into | 「深く分け入る」「深掘りする」 | 「詳しく調べる」「具体的に見ていく」 |
| it is not X, it is Y | 「XではなくYです」 | Xを削っても通じるなら「Yです」。誤解の訂正や見方の切り替えを担っているなら否定を残す（「Aに加えてB」などに変えない） |

## 急増した比喩語・評価名詞

AI以後の技術文書で増えた、中身の薄い比喩や評価の名詞。字義どおりの意味で使われているなら残し、飾りなら、元の文にある情報の範囲でふだんの言葉に開く。

- 障害・失敗の比喩: 事故、混ざる、落とし穴、破綻、実害、素通り → 「思いがけない失敗」「入り込む」「見落としやすい点」「うまくいかなくなる」「実際の困りごと」「気づかず通る」
- 確認・検証の比喩: 実測、疑う、照合、突き合わせる、断定、取り違える → 「実際に測った値」「念のため確かめる」「照らし合わせる」「見比べる」「言い切る」「間違える」
- 役割・位置の比喩: 入口、土台、道具、核心、主役、構図、線引き → 「はじめの一歩」「基本」「手段」「いちばん肝心な点」「中心」「全体の仕組み」「境界」
- 評価・結論の定型: 既定、別物、定番、要点、定石、桁違い → 「もともとの設定」「まったく違うもの」「よく使われるもの」「大事なところ」「標準の進め方」「段違い」

## 体験の壮大化・質感を装う語

個人のささやかな体験や日常の技術判断を、重い熟語や質感の語で大げさに語る型。

- 壮大化の熟語: 真理、真実、結末、宿命、運命、境地、極致、究極、虚飾、虚像、美学、深淵、禁欲的、優美、冷徹、残酷、凝縮、結晶 → 素朴な実感の言葉に戻す（「この道具の真実が見えてくる」→「この道具の本当の良さが見えてくる」）。元にない架空の固有名詞や普遍の教訓を足さない
- 質感を装う語: 手触り、肌感、体温、温度感、熱量、血の通った、泥臭い → 元の文や前後から分かる範囲で客観的な事実を書く。情報が足りなければ作り話を足さず、同じ幅のふだんの言葉で書く
- 認知・評価を装う語: 解像度（を上げる）、腹落ち、メンタルモデル、本質、本質的、地に足のついた、等身大 → 何をどこまで調べたのかを、元の文にある情報の範囲で書く。「本質」「核心」が文の主題や論点そのものになっているときは、「目的」など別の概念にすり替えず、「いちばん肝心な点」のような平易な言葉にするか、そのまま残す
- 未定義の造語: 「意思決定OS」のような勝手な比喩命名 → 平易な言葉や客観的な機能説明で書く

## 前置き・後置きのメタ宣言

読者の感情や理解度を先回りして誘導する、中身のない前置きや後置き。

- 前置き: 「重要なのは」「結論から言うと」「正直に言うと」「避けたいのは」「ここで注目すべきは」 → 単なる前置きは削って主文から書き始める。ただし「何が大事か」という評価そのものを担っているなら、削らずに述語へ移して残す（「〜が大事です」）
- 後置き: 「〜というわけです」「〜に他なりません」「〜と言えるでしょう」「面白いのはここです」 → 客観的な記述で文を閉じる。元が推量（〜でしょう、〜と考えられます）なら、断定に上げず推量の強さを保つ
- 定型の結び: 「いかがでしたでしょうか」「ぜひ試してみてください」「〜の参考になれば幸いです」 → 形式的な呼びかけを削り、本文の自然な結びで終える

## 拡張リスト（目視で確認したい表現）

「〜と言われています」の伝聞への逃げ、「〜かもしれません」の乱用による曖昧化、「〜していきたいと思います」の意志薄弱な言い切り回避、「様々な」「多様な」で具体を省略する癖、「〜ということです」で終わる伝聞的まとめ、「まさにその通り」の同意演出、「〜ではないかと思います」の二重の曖昧化、「〜という声もあります」の匿名の権威づけ、「今回は〜について紹介します」という予告口調の冒頭、「ぜひ〜してみてください」という締めの定型句
