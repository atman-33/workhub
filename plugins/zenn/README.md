# zenn

Writing Zenn tech-blog articles.

Kept separate from `authoring` on purpose: these two skills are needed only on
the days an article is written, and never alongside the other plugins' skills.
That is exactly the case where a separate plugin earns its keep — everything it
carries stays out of every other session.

## Install

Install at user scope so it is available from any working directory:

```
claude plugin install zenn@workhub-marketplace
```

## Skills

| Skill | For |
|---|---|
| `zenn-blog-writing` | the house style: technical accuracy, readability, no AI-ish prose |
| `zenn-markdown` | Zenn-flavoured Markdown (message blocks, accordions, embeds) |

No vault or project-context dependency.
