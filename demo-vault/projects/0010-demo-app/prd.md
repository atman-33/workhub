# Demo App — PRD

Fictional sample content. Used to populate workhub's screenshots.

## Problem

Notes taken during a working day end up scattered across three tools, and none
of them is searchable from the keyboard alone.

## Goals

- Capture a note in under two seconds from anywhere.
- Find any note by typing part of its text.
- Keep every note as a plain Markdown file on disk.

## Non-goals

- Sync between machines. The first version stays local.
- Collaboration, comments, or sharing.

## Scope

Capture, list, search, edit, delete. Everything else waits for a later
milestone.
